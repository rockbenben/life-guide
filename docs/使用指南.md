# 使用指南

这个 App 有两层：**App 给你看今天做什么**，**内容管线替你把 113 篇手册变成卡片**。
界面只写一遍，跑在三种壳里：**浏览器（PWA）、电脑（Electron 独立应用）、手机（Capacitor 独立应用）**。
这份指南讲两段：怎么装起来、每天怎么用。
（内容审阅、签字与决策门那些是你自己的活，写在 [AGENTS.md](../AGENTS.md) 里，末节有指路。）

---

## 一、装起来

三种形态跑的是**同一份构建产物**（`app/dist`），所以第一次都要先构建：

```bash
npm install
npm run app:build        # 产出 app/dist/（纯静态文件）
```

### A. 电脑：Electron 独立应用

```bash
npm run desktop:start     # 立刻起一个窗口试跑
npm run desktop:build     # 打包成安装包
```

产物在 `desktop/release/`：Windows 出 NSIS 安装包（x64 / arm64 合一）与双架构免安装版；
macOS 出 `.dmg` + `.zip`（未签名，首次打开要右键 →「打开」，且不接自动更新）；
Linux 出 `.AppImage` + `.deb` + `.rpm`（AppImage 版接自动更新；deb / rpm 版请手动换新包）。
Windows 包也还没签名，首次运行会有 SmartScreen 提示；`npm run desktop:build` 只打当前系统，三平台一起打是发版流水线的事。

**能自己更新的形态**：Windows 的**安装版**与 Linux 的 **AppImage 版**（免安装版、macOS、deb / rpm 都不行）。
更新是「查」不是「偷偷下」：启动时查一次有没有新版本，查到了弹一条系统通知，
到「设置 → 更新」里点「下载更新」才下 —— 双架构合一的安装包两百多兆，你点了才下。
装完把 App 重启一下就换好了。

装完是**真正的独立应用**：自己的图标、独立窗口、没有地址栏、没有浏览器工具栏，
数据存在本机的应用数据目录里（IndexedDB，跟浏览器版各存各的）。

**关窗口不是退出**：点右上角的 × 只是把窗口收起来（托盘里还在），
这样早 / 晚的提醒照样会响 —— 进程还在，提醒就还在。
真要退出：托盘图标右键 →「退出」。
窗口的大小和位置会记住，下次打开还是上次的样子。

想确认它真的能起来（而不是装上了白屏）：

```bash
node scripts/desktop-check.mjs    # 真的拉起窗口、截图、检查有没有报错
npm run test:desktop              # 桌面端那几块纯逻辑的单测
```

### B. 手机：Capacitor 独立应用

原生工程已经生成在 `mobile/android/` 与 `mobile/ios/`。

```bash
npm run mobile:sync        # 把最新的 app/dist 同步进原生工程

# Android：出 APK
npm run build:android --workspace @life-guide/mobile
# 产物：mobile/android/app/build/outputs/apk/debug/app-debug.apk

# 或者用 Android Studio 打开（要签名、调原生能力时更方便）
npm run open:android --workspace @life-guide/mobile
```

**Android 构建要 JDK 21**（Capacitor 8 的要求）：`java -version` 不是 21 的话，
Gradle 会报「Cannot find a Java installation matching {languageVersion=21}」。
装个 JDK 21，或者在 `~/.gradle/gradle.properties` 里指给 Gradle 认得的那一个 ——
Android Studio 自带的 JBR 就是 21：

```properties
org.gradle.java.installations.paths=C:\\Program Files\\Android\\Android Studio\\jbr
```

**Node 要 26**（`package.json` 的 engines 写死了）。CI 也用 26。

**iOS 必须在 macOS 上构建**（需要 Xcode 与 CocoaPods）。工程已经生成好了，
拿到 Mac 上 `cd mobile/ios && pod install && open App.xcworkspace` 就能编
（iOS 15 以上，Capacitor 8 的要求）。

装到手机上：

- **Android**：APK 直接传到手机安装；或 `adb install` 走 USB
- **iPhone**：用 Xcode 跑，或把 App 传 TestFlight / App Store Connect

### C. 浏览器：PWA（最省事，也能当 PWA 装）

部署到 **HTTPS**（Service Worker 只在 HTTPS 或 localhost 注册，HTTP 下离线功能
和「添加到主屏幕」都不工作）。EdgeOne Pages / GitHub Pages / Netlify / 自己的 Nginx 都行。

**产物是 `app/dist`，一份就够**（`npm run app:build`）：

- 里面所有路径都是**相对**的，所以放在子路径也能跑 —— 桌面端与手机端跑的是同一份产物。
- 部署时给它一个**绝对域名**当社交预览的图：`OG_IMAGE_URL=https://你的域名/og.png`
  传给构建（`index.html` 里的占位符由 `app/vite.config.ts` 替换）。
  不给的话落成相对路径 —— 分享出去时那张图会坏。
- CI 的 `desktop` / `acceptance` job 会构建或使用 `app/dist`。
  桌面端与 Android 的正式发布走 `release.yml`（打 tag 触发，产物直接传进发布草稿）；
  浏览器这条路的 `deploy.yml`（推 `gh-pages` 给 EdgeOne）**目前是禁用状态** ——
  域名与 EdgeOne 那边配好之后再打开。

发布的具体步骤见 [`部署.md`](部署.md)。

- **iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android / 电脑（Chrome、Edge）**：菜单 → 安装应用 / 地址栏的安装图标

> ⚠️ 装之前先在设置页导出一次数据 —— 不装到主屏的 Safari 站点，长期不访问会被
> 系统回收本地数据（AGENTS.md §8）。

### 三种形态各自适合什么

- **手机**：每天做。点方格盖个印、看提醒、按模式换步骤。
- **电脑**：查。想找某个动作怎么做、原文怎么说的，「手册」里搜比在手机上翻快得多。
- **浏览器 PWA**：不装也能用，适合临时看一眼（或者你不想装任何东西）。

> 三种形态的**数据是各存各的**：手机 App 里的记录不会自动同步到电脑。
> 想合并就用设置页的「导出数据 / 导入数据」。

## 二、每天怎么用

### 打开就是「今天」

- 顶上第一行是**时段**：早 / 日间 / 晚。默认跟着钟点走（现在几点就落在哪一段；
  凌晨 04:00 前仍算前一天的晚间），也可以手动切 —— 想在早上看看晚上要做的事，点一下就行。
  从日历提醒点进来的链接会直接落到对应的那一段。
- 列表里只有**你自己挑进日常的那几张**（加上「随时」都能做的那些），不是手册里所有能做的动作。
  全铺出来的话光是「随时」类的就有几百张，那不是清单是目录。
  卡片左边那个时段标签是**按手册原文标的**：原文只说「睡前」才标「晚间」，
  原文说「早晚各一次」或者压根没提时间，就标「随时」—— 那一档的意思是「哪一段都能做」。
  **第一次打开时 App 会替你放好 16 张**：手册「每天固定做的几件事」那两节的 8 张
  （晨光、睑缘清洗、洗脸、刷牙、牙线、3T 保湿、血管拉伸、睡前鼻腔冲洗），
  再按早 / 日 / 晚每档补几张 —— 补的都是手册里写着「每天做」的动作，
  免得某一屏打开是空的。次序**按时间排** —— 早、晚两段的动作在前，
  「随时」那几张在后面。不用先做一次设置。
- 想改：**展开任意一张**，末尾有两个不同的动作：
  - **今天不做**：只跳过这一天，明天自动回来；清单上方「今天不做」可以撤销，日常清单不动。
  - **移出日常**：以后都不再出现；手册或「发现」里还能再加回来。
  **条件那一行下面的「调顺序」**能上下挪 —— 挪过的次序就是你之后看到的次序，刷新也还在。
- **手册里没有的习惯，你自己加**：今天页左边那颗**「加自己的习惯」**，
  填「叫什么」「做什么（可以不填）」「什么时候做」，保存就进你的日常。
  - 它跟你从手册里挑的动作**一样**：能盖章、能算累计天数、能单独设闹钟、能调次序。
  - 展开它，页脚写着「你自己加的」，那两颗键是**「改」**和**「删掉」**——
    自己加的习惯只有一处存在（你的日常里），删掉就是真删。
  - **时段是你说的**，不是手册说的 —— 手册那张卡左边标「晚间」是因为原文写了「睡前」。
  - 只存在这台设备上；**换设备要用「导出数据 / 导入数据」把它带过去**。
  - 「今天不做」也存本机、随 JSON 备份走；它不是盖章记录，清空记录不会清掉它。
- **闹钟 App 自己会响**：设置 → 提醒 → 点「允许通知」，时刻可以改（早 / 晚各一个）。
  响的时候直接告诉你这一段该做哪几件。
  手机端**关掉 App 也会响**（系统排程）；桌面端关窗口只是收进托盘、进程还在，提醒也会响，
  托盘右键退出后就不响；浏览器里只有 App 在前台才准 —— 后台标签页会被浏览器压住，通知可能晚几分钟，
  所以浏览器那条路建议再导一份日历。
- **每张卡也能单独设提醒**：展开那张卡 →「提醒」那一行 →「设提醒」。
  挑一种方式：**每天 / 每周（可多选周几）/ 隔几天 / 就一次**，再挑时刻。
  新建时默认模式跟着卡的频率：周卡默认每周当天，月卡默认每隔 30 天；已有提醒不改。
  设好的会写在那张卡上（写着「每天 08:30」这样的字样），设置页里也列得出、也删得掉。
  当天点了「今天不做」的卡，它今天的提醒会跳过，明天照常。
  （手机端这一跳会退成一次性排程，App 每次打开会自动续上。）
- **Android 手机上第一次用**：设置 → 提醒里若出现「去允许精确提醒」，点它、
  在系统里打开「闹钟和提醒」。不打开的话 Android 会把闹钟攒着一起发，提醒会晚几分钟。
- 每张卡收起的是三行：**名**（内容层给的动作名；没有才用原文小节名）/ **做什么** / **剂量**，
  外加 **stop 级禁忌** —— 禁忌永远可见，展开才看步骤与细节。
  **「做什么」那一行有时不显示**：它与「名」说的是同一句话时就不重复摆了
  （比如「睡前用生理盐水冲鼻腔」下面不会再跟一句「睡前用生理盐水冲洗鼻腔」）。
  原文在展开态的「做什么」那一行仍然看得到。
- 展开之后是一张用法用量表（剂量 / 做什么 / 时段 / 频率 / 提醒 / 耗时 / 见效）加步骤。
  **频率**决定这张卡多久出现在今天；周 / 月卡完成后收进「本周期已完成」，
  撤销只把这张卡放回来：这次完成不再算累计，今天这一格重新空出来；
  更早按每天做过的记录仍然保留。
  剂量表里的数**都是原文里的数**：原文写「32 到 34℃」就显示「32～34 ℃」一条，
  不拆成「下限 / 上限」两条；原文写「1/2 小勺」而换算成 0.5 的，会标「推算」并给出算式。
  卡片上的每一步、每条禁忌都是**原文的话**，不再另摆一份引文；
  要去逐字对质，看展开态最底下那句「出自〈哪一篇〉」，点它跳到手册里的那一篇。
- 第二行是**条件**（点开才展开）：模式（正常 / 很忙 / 出差 / 生病）与我的情况
  （年龄段 + 易跌倒 / 膝盖不适 / 孕期 / 经期）。设置页里也能改，改的是同一份。
  - **模式**设计上会换掉步骤 —— 当前有 15 张卡带模式版本（14 张忙档、1 张生病跳过，
    0 张出差）。有对应版本的按模式改，其余照常做；设置页会显示当前清单里各模式各有多少张。
  - **我的情况**决定**人群分档**：比如「易跌倒」会把踮脚换成低冲击的版本，
    剂量也跟着换（默认的量属于默认动作，不跟着走）。年龄段只能选一个。
    少数几张卡会按你选的情况换动作，其余照默认做就行。
- 做完就点卡片右边那个方框 —— 它盖的是一枚**当天的日付印**，不是打勾。
  **断签不清零**：界面显示「已做 N 天」，对应原文说的「连续 5～6 个月才显现效果」。
  页边那一排 14 格印迹就是让你看见「断过，但没清零」。主动撤销一次周期完成会扣掉那一次，
  但更早的记录还在。
- 卡片上方那行总览是全局的进度：今天几个动作、盖了几印、**累计多少天**。

### 更新过 App 之后（清单怎么恢复默认）

给已经用过一阵子的人：

- **你的清单是你自己的，App 不会悄悄换掉它。** 内容是跟着 App 走的（现在 App 里有 423 个
  能照着做的动作），但「今天」那一屏仍然是你存过的那份 —— 你手动挑过、删过、排过序的东西，
  不会因为 App 更新就没了。新动作从「发现」每天来一张，手册里 113 篇能翻、88 篇有动作卡。
- **想换回 App 给的那张默认清单**：今天页顶部 → **「放回默认」**（跟「调顺序」并排，
  一进今天页就看得见）。点一下就回到内容层当前的默认清单：按清单分组是早晨 3 /
  日间 3 / 晚间 3 / 随时 7，共 16 张，次序按时间排。
- **清单被你自己清空了**：今天页会变成空态，那里面有一颗 **「放回默认」** —— 同一个恢复动作。
- 这两颗键都是**替换**：点了之后你挑的那几张会被默认清单顶掉（毕竟是你点的按钮）。

### 发现层

「今天」下面有一节**发现**：每天给你三张**还没进你日常**的卡，试试看，喜欢就点「放进日常」，
不合口味点「换一批」。这些卡是只读的 —— 真正要盖章的还是「今天」列表里的。
它同时告诉你「手册里还有 N 个动作没进日常」，那 N 个都在「手册」里，按篇翻。

### 「手册」

113 篇全文（快照根下那个 README 是这本书的目录页，不算一篇），可以搜标题和正文，也可以按**身体 / 饮食 / 思维 / 生活**四类翻。
疾病类的文章在「今天」里不出现，只在这里，页首会有一句「本页是疾病知识，不是治疗方案」。
每篇下面标了它抽出了几个动作 —— 标了数字的就是能照着做的（现在 113 篇里有 88 篇有动作卡；
15 篇是疾病知识；其余 10 篇只有正文，没有可执行卡）。

### 日历提醒（浏览器里建议再导一份）

设置 → 提醒 → 导出日历（含卡片提醒）→ 导入系统日历。

会得到早 / 晚两条每日重复的整段事件（默认 7:00 与 21:00，各带提前 10 分钟的提醒），
以及你设过的卡片提醒（按每天 / 每周几 / 隔几天 / 一次展开）。
当天标了「今天不做」的卡，会在这次导出的日历里把当天那次排除掉；
某一时段的卡全跳过时，该时段的整段事件也会排除当天。

**App 自己也会响**（手机与桌面端最稳）—— 但浏览器里的 App 一进后台就可能被压住，通知会晚几分钟，
所以浏览器这条路把日历当备份更靠得住。

### 定期导出

设置 → 导出数据 → 得到一个 JSON。**每周导一次**，这是你唯一的后台数据。
（这套东西到底值不值得继续做，见 AGENTS.md §7 的决策门。）

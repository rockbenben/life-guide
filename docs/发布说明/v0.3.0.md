这一版把「换设备」这件事做完了：多台设备可以共用同一份数据，但**默认一个字节都不出去** —— 要开同步得你自己在设置里开，开了之后上传的也只有密文。

这一版加了这几件事：

- **多设备同步（可选，默认关）**：三种落点 —— 网盘 WebDAV、GitHub 私有仓库、仓库里自带的那个自建服务。口令同时派生出空间编号与加密密钥，所以服务端拿到的只有密文；口令本身不出设备。
- **局域网里的 WebDAV 也能连**：桌面端与 Android 手机走的是系统自己的网络栈，不受浏览器跨域限制 —— 自建的 nginx dav、NAS 里那台都能用（浏览器端仍不支持，界面里写明了）。
- **同步省流量**：先问一句「还是那一版吗」（ETag / 304），没变就几百字节收工；只在真有变化时才上传，应用开着时每隔几分钟也会自己查一次。
- **同步设置页重做了一遍**：一段话加一个可展开的说明，选项名短了；地址少了协议时会直接说「地址格式不对」，不再笼统报「网络不通」。三个真问题也修了：服务端回 304 时本地的改动会被吞掉、账号密码里带非拉丁字符会报错、「正在同步」被当成失败会让自动同步冷却五分钟。
- **卡片合并了**：38 张拆得太散的卡并成了 14 张（产品里的卡从 518 张降到 491 张）。合并后的卡保留了被并卡的每一步、每条剂量、每处禁忌；你已有的记录靠 formerIds 认领回新卡。审查也补了「子集」这一项 —— 一张卡的每一步都在另一张卡里时，相似度算不出重复。
- **标记重画**：从「一张卡加一枚印」改成「一个站着的人，胸口别着今天的印」 —— 这个应用多半是在讲身体的事，印是仪式。托盘图标也跟着换了（16px 另画了一版小标记）。
- **手机上展开的卡，点别处就收起**：读完想合上不用一路滚到卡末；卡里的东西点了不收起（正在读剂量时卡就没了，那比不收更糟）。
- **文档跟代码对齐**：卡数、测试数、预缓存大小这些数字逐个重新量过。

这一版有什么：

- **Windows**：安装包（NSIS，x64 + arm64）与双架构免安装绿色版
- **macOS**：dmg + zip（Intel / Apple Silicon）
- **Linux**：AppImage + deb + rpm（x64 / arm64）
- **Android**：APK（debug 签名，可直接安装；用「允许通知」后才排程）
- **浏览器**：PWA —— **<https://life.newzone.top/>**（可装到桌面与手机；首次打开会在后台预缓存，约 3.9 MB，缓完就能完全离线用）

数据只在本机，不上传、没有账号。换设备用「导出数据 / 导入数据」。

完整的说明与限制见仓库 README 与 docs/使用指南.md。

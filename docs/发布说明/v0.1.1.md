《生活手册》的卡片版：113 篇手册 → 518 张卡（423 张动作 + 95 张疾病知识），每一步、每条禁忌都对着原文核过。

这一版加了两件事：

- **桌面端能自己更新了**：启动时查一次有没有新版本，查到了弹一条系统通知；到「设置 → 更新」里点「下载更新」，下完重启一下就装上。下载不会自动开始 —— 双架构合一的安装包两百多兆，你点了才下。Windows 安装版与 Linux 的 AppImage 版支持；macOS 版、Linux 的 deb / rpm 版与免安装版请手动换新包。
- **发版改成流水线**：打个 tag，流水线自己校验版本、跑测试、打包三平台桌面版与 Android，生成校验和，发到草稿等人放行。以后发版不用手工一步步来。

- **Windows**：安装包（NSIS，x64 + arm64）与双架构免安装绿色版
- **macOS**：dmg + zip（Intel / Apple Silicon）
- **Linux**：AppImage + deb + rpm（x64 / arm64）
- **Android**：APK（debug 签名，可直接安装；用「允许通知」后才排程）
- **浏览器**：PWA，首次加载后可完全离线使用

数据只在本机，不上传、没有账号。换设备用「导出数据 / 导入数据」。

完整的说明与限制见仓库 README 与 docs/使用指南.md。

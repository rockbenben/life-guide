《生活手册》的卡片版：113 篇手册 → 518 张卡（423 张动作 + 95 张疾病知识），每一步、每条禁忌都对着原文核过。

这一版加了这几件事：

- **「今天不做」只跳过今天**：卡展开后末尾那颗「今天不做」，当天不再出现、它的提醒当天也不响，第二天自己回来 —— 不用为了今天状态不好就把动作从清单里删掉。旁边那颗「移出日常」才是永久移出。
- **手册能按卡名搜**：今天页上看到的名字（比如「晨光」），在手册里也能搜到 —— 那些名字是内容层起的策展名，原文里未必有那个词，搜索在自己的词汇表上失灵，会让人认定「搜不准」而不再用。
- **剂量里的「约」如实显示**：原文写「约 5 次」的，屏上就是「约 5 次」，不再是一个看着像定值的数。全文 56 行剂量已按原文逐行标好。
- **界面重排**：卡片、设置、发现面板重新排过一遍，触控目标放大到 44px，折叠区与行距也调了 —— 原来的版本在窄屏上挤，桌面上也散。
- **桌面端能自己更新了**：启动时查一次有没有新版本，查到了弹一条系统通知；到「设置 → 更新」里点「下载更新」，下完重启一下就装上。下载不会自动开始 —— 双架构合一的安装包两百多兆，你点了才下。
- **发版改成流水线**：打个 tag，流水线自己校验版本、跑测试、打包三平台桌面版与 Android，生成校验和，发到草稿等人放行。以后发版不用手工一步步来。

这一版有什么：

- **Windows**：安装包（NSIS，x64 + arm64）与双架构免安装绿色版
- **macOS**：dmg + zip（Intel / Apple Silicon）
- **Linux**：AppImage + deb + rpm（x64 / arm64）
- **Android**：APK（debug 签名，可直接安装；用「允许通知」后才排程）
- **浏览器**：PWA —— **<https://rockbenben.github.io/life-guide/>**（可装到桌面与手机；首次打开会在后台预缓存，约 3.9 MB，缓完就能完全离线用）

数据只在本机，不上传、没有账号。换设备用「导出数据 / 导入数据」。

完整的说明与限制见仓库 README 与 docs/使用指南.md。

这一版主要把「浏览器那条路」真正接通，另外修了几处会让通知、日历对不上的小毛病。

- **浏览器版现在有正式地址了**：<https://life.newzone.top/> —— 装到桌面或手机上都行，首次打开在后台预缓存（约 3.8 MB），缓完就能完全离线用。GitHub Pages 的 <https://rockbenben.github.io/life-guide/> 是同一份产物的镜像，两个地址伺服的是同一个版本。
- **通知不再顶着空图标**：图标路径改成相对的 —— 同一份产物跑在主地址或镜像的子路径下都能取到图标（之前在子路径下会 404，通知只剩一个空白方块）。
- **导出的日历不会多出一份早晨提醒**：事件 UID 保持不变，不跟着站点域名改 —— 日历靠它判断「同一条事件，该更新」而不是「新事件」。要是跟着域名改了，已经导入过上一版的人会平白多出一份重复的提醒。
- **桌面端内核更新到 Electron 45.1.0**。
- **发版流水线跑通了**：这一版起，打个 tag 就自动校验版本、跑测试、打包三平台桌面版与 Android、生成校验和，发到草稿等人放行。产物直接传进发布草稿，不再经过中转。

这一版有什么：

- **Windows**：安装包（NSIS，x64 + arm64）与双架构免安装绿色版
- **macOS**：dmg + zip（Intel / Apple Silicon）
- **Linux**：AppImage + deb + rpm（x64 / arm64）
- **Android**：APK（debug 签名，可直接安装；用「允许通知」后才排程）
- **浏览器**：PWA —— **<https://life.newzone.top/>**（可装到桌面与手机；首次打开会在后台预缓存，约 3.8 MB，缓完就能完全离线用）

数据只在本机，不上传、没有账号。换设备用「导出数据 / 导入数据」。

完整的说明与限制见仓库 README 与 docs/使用指南.md。

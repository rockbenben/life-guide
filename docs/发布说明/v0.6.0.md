这一版不用你搬数据，升级后原来的记录、习惯和提醒都还在；大多数人打开就能用，只有同步相关的少数设置要留意。

### 破坏性变更

- 自己搭中转服务的人：新版服务端要求写入时带上一个令牌，旧版 App 会被拒绝写入，同步会失败。先重新部署服务端、设好令牌，再把各设备升级到这一版，在同步设置里填上同一个令牌。部署步骤见[同步服务说明](https://github.com/rockbenben/life-guide/blob/v0.6.0/sync/README.md)。

### 新增

- 今天、手册、设置三页换了新样子：手机上管理清单的入口收进一栏；手册页分成左右两栏，常用动作收进「全部」分类里。
- 卡片里的耗时可以直接计时：给了时长的倒计时，没给的用正计时；分步的卡按步走，归零自动跳下一步，能暂停、上一步、重做，也能补做漏掉的步骤。

### 修复

- 手机上改一条提醒，不再把这一批系统通知全删了重排；排程失败时设置页会说明并给重试入口。以前合并过的卡片上的提醒，也会跟着搬到新卡上。
- 多设备同步：每个同步位置分开保存，换位置不再冲掉另一个位置的账号；网盘同步如果之前没有成功同步过，升级后要重新填一次账号密码。另外修了几处会悄悄出错的地方：数据变大后 GitHub 那条路不会读成空；远端没变时会把两边完整再合一遍，本地改动不会被卡在「不用传」。

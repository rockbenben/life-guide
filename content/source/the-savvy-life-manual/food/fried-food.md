天妇罗刚炸好很脆，放一会儿就软塌；下锅时油点还四处飞溅？这两件事的开关都出在「水」而不在「油」。

**防软塌**是在调面衣时**先把油拌进面粉**（先油法）——实测放置 10 分钟后面衣含水量 **12.5%**，已经逼近料亭的 **10%**；**防油溅**是把食材切好、平铺互不重叠、**不裹保鲜膜冷藏一晚（约 16 小时以上）**，利用冰箱除湿让食材适度脱水。下面先给这两招、三份食谱和酥脆土豆，成因放在最后。^[[「揚げ物」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_agemono.pdf)]

## 先拌油：让面衣少吸水的唯一开关

让酥脆维持更久的办法是「先油法」——**在裹面衣之前，先把油拌进面糊里**。

原理在于面衣本身的成分：面粉和水混合后会生成一种叫**谷蛋白（麸质）**的蛋白质，它是撑起面衣立体结构的关键；但同时，谷蛋白的网状结构天生**容易吸水**。先把油拌进面粉，油就像给面粉裹了一层防水膜，把水挡在外面，能生成的谷蛋白大幅减少，面衣自然就吸不进那么多水。

实测结果：用先拌油法炸的天妇罗，放置 10 分钟后面衣含水量为 **12.5%**，已经逼近老铺料亭的 10%。^[[「揚げ物」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_agemono.pdf)]

## 抑制油花飞溅：食材要"过夜风干"

长崎县对马市一家海鲜食堂的炸鱿鱼很特别——味道浓而且**非常甜**，而且**整个炸制过程完全不溅油**。秘密是对马的传统做法——把鱿鱼**过夜晾干**：当地用一种专用的旋转脱水装置把鱿鱼晾上一夜。

之所以有效，是因为**油花飞溅的根源就是食材里的水**。水变成水蒸气时，体积会急剧膨胀约 **1700 倍**，把周围的油弹飞。过夜晾干让水分适度流失、味道浓缩，意外地连油溅一起解决了。

### 家庭版：不裹保鲜膜冷藏

没有脱水机也能做到，利用冰箱就够。冰箱内部在冷却时会除湿，食材能自然适度脱水。

1. 把新鲜食材**切好**。
2. 平铺在托盘里，**互相不要重叠**。
3. **不裹保鲜膜**，直接放进冰箱冷藏。
4. 放置一晚，即**约 16 小时以上**。

适合处理的食材：

- 鱿鱼、章鱼、虾等海产类——鲜味成分会得到浓缩
- 芋头、莲藕等根茎类——糖分浓缩，风味更足

两点务必注意：存放过久会产生气味、成为杂菌繁殖的原因，**务必一晚后就烹调**；另外带加湿功能的冰箱可能没有效果，使用前请确认冰箱说明书。（成分分析协力：学习院女子大学 品川明教授）

## 三份食谱

### 天妇罗（2～3 人份）

| 材料 | 用量 |
| --- | --- |
| 低筋面粉 | 100g |
| 油 | 3 大勺（40g） |
| 水 | 180ml |
| 低筋面粉（防粘用） | 适量 |
| 炸油 | 适量 |
| 喜欢的食材 | 适量 |

1. 把油和水混合均匀，再加入低筋面粉，搅拌成面衣。
2. 食材先薄薄裹一层防粘面粉，蘸上面衣，放入 **180℃** 的油中炸。
3. 面衣边缘微微变成茶色即可。

炸制时间目标：蔬菜约 **3 分钟**，鱼贝类约 **1 分～1 分 30 秒**。比平时**稍微多炸一会儿（时间略长一点）**，正是保持酥脆的要点。

### 炸鸡（2 人份）

| 材料 | 用量 |
| --- | --- |
| 鸡腿肉 | 1 块（约 300g） |
| 酱油 | 2 大勺弱 |
| 酒 | 2 大勺弱 |
| 姜蓉 | 少许 |
| 油 | 3 大勺 |
| 低筋面粉 | 4 大勺 |
| 低筋面粉（防粘用） | 适量 |
| 炸油 | 适量 |

1. 鸡腿肉切成一口大小。
2. 鸡肉和调料（酱油、酒、姜蓉、油）放入塑料袋，揉搓到不粘粉的程度。
3. 在②的鸡肉上薄薄裹一层面粉，放入 **160～170℃** 的油中炸约 **4 分钟**，先取出。
4. 把油温升到 **180℃**，将③再炸约 **2 分钟**。

### 洋葱圈（2 人份）

| 材料 | 用量 |
| --- | --- |
| 洋葱 | 1 个 |
| 低筋面粉 | 100g |
| 油 | 40g（约 3 大勺） |
| 水 | 110ml |
| 鸡精颗粒 | 1 小勺半（5g） |
| 盐 | 1/2 小勺（2.5g） |
| 低筋面粉（防粘用） | 适量 |
| 炸油 | 适量 |

1. 把油和水混合均匀，加入低筋面粉，搅拌成面衣。
2. 在①的面衣中加入鸡精颗粒和盐，搅拌均匀。
3. 洋葱切成约 **1cm** 厚的圆环，薄薄裹上防粘面粉。
4. ③蘸上面衣，放入 **170℃** 的油中，炸至面衣上色，约 **3～4 分钟**。

把第 2 步里的鸡精颗粒和盐换成香料，就是一份香料味的炸物面衣。

## 附：酥脆土豆

这道「酥脆土豆」用的是冷冻油炸法，冷冻过的土豆内部水分结冰后炸出来格外酥松。

**材料（2 人份）**：带皮土豆 2 个（约 260g）、炸油适量。

1. 土豆切得厚一些——6～8 等分的条状，或 1.5cm 见方的滚刀块。
2. 铺在耐热盘上，轻轻盖上保鲜膜，用微波炉 **600W 加热 4 分 30 秒**。
3. 加热后取下保鲜膜，放至不烫手。
4. 放凉后整体用保鲜膜包好，冷冻保存。
5. 油温调到常温，把**冻结状态的土豆**下锅，大火炸约 **3 分钟**。
6. 油面翻滚沸腾后，调到弱火与中火之间的火力，再炸 **12 分钟**。
7. 捞出静置约 **3 分钟**，再回锅用大火炸约 **1 分钟**，完成。

加热过程中粘在一起的土豆，要随时分开。^[[「揚げ物」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_agemono.pdf)]

## 面衣变软，主因是水而不是油

香川县有一家老铺料亭，端出来的天妇罗放足 **1 小时半**，面衣依旧爽脆。节目组把"家里做的天妇罗"和"料亭的天妇罗"分别炸好后放置 **10 分钟**，送检面衣含水量，结果差距悬殊：

- 老铺料亭：约 **10%**（实测 10.2%）
- 一般家庭：**32%**（实测 31.9%）——整整 3 倍

关键不在油炸得多好，而在于食材渗出的水被面衣吸了进去。面衣吸饱水，网格结构被泡软，口感就从刚出锅的酥脆一路滑到软塌黏烂。

faq:
  - question: 杏鲍菇怎么烤才多汁，切片还是整根
    answer: 整根烤，不要切片。杏鲍菇原产地属地中海干燥气候，富含负责保水的海藻糖，因此整根烤也不易干。但一切片，那层吸水的表皮就会从断面蒸发掉，水分跑光。想要惊讶的多汁感，请用 200℃ 烤箱或烤面包机把整根杏鲍菇烤 10 分钟，或切大块裹培根烤 15～20 分钟。
  - question: 土豆泥为什么比直接煮土豆更黏稠
    answer: 土豆淀粉的黏度实测约为玉米淀粉的 8 倍以上（对照实验中土豆读数 250、红薯 67、玉米 30）。但淀粉颗粒被坚固的细胞壁包着，普通煮法发挥不出来，必须用擦泥器把细胞壁破坏、淀粉颗粒释放出来，才能煮出真正的黏度。
  - question: 醋到底放多少，会不会把菜弄酸
    answer: 目标是菜品总量的 0.5%～1%。放多了会发酸，所以从 3～4 滴起步。一人份的汤或炒菜只需几滴，两人份约半小勺，3～4 人份 1～2 小勺；一人份的小钵菜 1～2 滴就够。加完要充分搅匀，没混匀的菜几乎尝不到效果。
  - question: 蒜切碎了炒为什么没有蒜香味，大蒜水怎么做
    answer: 蒜切碎或擦泥会破坏细胞，alliin（蒜氨酸）在酶作用下变成 alicin（大蒜素），香气就跑了。把蒜切片泡进沸水能同时解决两个问题：热让酶失活保住 alliin，水把易溶的 alliin 带出细胞。做汤用 500mL 水配 3g 蒜片（2～3 片）煮 5 分钟以上；炒菜用 100mL 水配 9g 蒜片（1～2 瓣）加 2 撮盐煮 5 分钟。

同样的食材，为什么有人做得多汁、有人做得寡淡？杏鲍菇、土豆、醋和大蒜**各有一个被浪费掉的开关**。

**杏鲍菇整根烤**（整根 **200℃ 烤 10 分钟**，或切大块裹培根 **200℃ 烤面包机 / 220℃ 烤箱烤 15～20 分钟**）；**土豆先用擦泥器擦泥**再下锅；**醋按菜品总量的 0.5%～1%**，从 **3～4 滴**起步；**大蒜切片后泡进沸水**——汤用 **500mL** 水＋蒜片 **3g** 煮 **5 分钟以上**，炒菜用 **100mL** 水＋蒜片 **9g**＋盐 **2 撮** 煮 **5 分钟**。下面先给醋的用量表和七道食谱，四种食材的原理放在最后。

**定位说明**：这篇是四种食材的**横向速查**——只回答「哪种做法能把这个食材的潜力打开」和「最快的量是多少」。同一食材的完整做法与更多食谱另有专篇：杏鲍菇见[杏鲍菇怎么切？四种 5mm 刀法，黄油煎 4 分钟](./eringii.md)，土豆见[土豆：冷一晚出抗性淀粉，磨泥出黏性](./potato.md)，大蒜见[大蒜别磨蒜泥？切片泡 90℃ 热水 10 分钟](./garlic.md)。

## 醋：几滴就够的用量表

醋的隐藏功能是**味道觉醒力**——几滴就能把整道菜的味道托起来：味道变清爽、素材的味道被引出、用水果做的饮品的**清爽感**提升。各种料理达人都在用少量醋，名称就叫「秘醋」。

用量目标是菜品总量的 **0.5%～1%**。放多了会发酸，所以请从 **3～4 滴**开始加，再逐步调整。

| 菜品（1 人份的量） | 1 人份 | 2 人份 | 3～4 人份 |
| --- | --- | --- | --- |
| 汤（250g） | 几滴 | 1/2 小勺 | 1～2 小勺 |
| 炒菜（200g） | 几滴 | 1/2 小勺 | 1～2 小勺 |
| 小钵（80g） | 1～2 滴 | 几滴 | 1/2～1 小勺 |

用量只是大致标准，食材不同需要微调。加醋后要**充分搅拌**，让醋均匀分布到整道菜里；混不匀的话，效果几乎感知不到。

适合用醋的菜：果汁（苹果、番茄、橘子等）、红薯意面、咖喱；此外卡波纳拉（奶油系）、甜品（香草冰淇淋）、水果鸡尾酒、炒菜等几乎所有料理都适合。

**秘醋的存放**：容器避免金属和木器，选玻璃、塑料或陶器；冷藏保存，**1 周左右**用完；一旦变质就停用。

## 食谱

### 杏鲍菇培根卷（2 人份）

选**偏大的**杏鲍菇，出锅后用剪刀剪成一口大的块状更方便吃。

| 材料 | 用量 |
| --- | --- |
| 杏鲍菇 | 2 根 |
| 薄切五花肉 | 4～6 片 |
| 融化型片装芝士 | 4 片 |
| 盐 | 少许 |
| 低筋面粉 | 适量 |
| 罗勒（可选） | 4 片 |

1. 五花肉轻轻撒盐调味，片面用茶筛等薄薄拍一层面粉。
2. 杏鲍菇的**轴部**放上芝士片，把拍过面粉的一面朝内，用五花肉紧紧卷起。
3. 放入 **200℃ 烤面包机或 220℃ 烤箱烤 15～20 分钟**。芝士会流出，务必铺铝箔。

### 杏鲍菇串烧（4 串份）

| 材料 | 用量 |
| --- | --- |
| 杏鲍菇 | 2 根 |
| 西葫芦 | 1/2 根 |
| 培根 | 2 片 |
| 小番茄 | 4 个 |
| 卡门贝尔奶酪 | 4 个 |
| 蛋黄酱 | 大勺 2 |
| 咖喱粉 | 小勺 1/4 |

1. 杏鲍菇**整根**放入烤箱或烤面包机，**200℃ 烤 10 分钟**后切成 4 等分。培根切一半煎香，同锅把西葫芦切成 **2cm** 厚片煎一煎。
2. 用竹签按杏鲍菇、西葫芦、培根、卡门贝尔奶酪、小番茄的顺序串起。
3. 蛋黄酱中拌入咖喱粉。
4. 吃的时候蘸着酱。

### 土豆泥浓汤（2～3 人份）

| 材料 | 用量 |
| --- | --- |
| 擦成泥的土豆（2～3 个土豆的量） | 大勺 6 |
| 鸡腿肉（撒少许盐切一口大） | 1 块 |
| 洋葱（切瓣） | 1 个 |
| 胡萝卜（切滚刀块） | 1 根 |
| 蘑菇（一分为二） | 8 个 |
| 黄油 | 20g |
| 水 | 400mL |
| 牛奶 | 300mL |
| 固体汤块 | 1 个 |
| 酱油 | 小勺 1 |
| 盐、胡椒 | 适量 |

1. 锅中放黄油化开，加入鸡肉翻炒。
2. 加入洋葱、胡萝卜、蘑菇，炒到洋葱变软；加水和高汤块，煮沸后转小火，盖盖煮到蔬菜变软。
3. 加入**土豆泥**，边煮边搅拌至起黏。
4. 黏度上来后加入**牛奶**，用酱油、盐、胡椒调味。

### 擦土豆团子（1 根的分量）

| 材料 | 用量 |
| --- | --- |
| 擦成泥的土豆（3 个小土豆左右的量） | 250g |
| 油 | 大勺 1 |

1. 耐热碗中放入去皮去芽后擦泥的土豆和油，轻轻拌匀，**不盖保鲜膜用 500W 微波加热 4 分钟**。
2. 取出用刮刀随意拌匀，再加热 **3 分钟**，然后聚拢揉成团。
3. 用保鲜膜搓成棒状，晾到不烫手。（很烫，小心烫伤！）

要点：

- 土豆要**去皮、去芽**后再擦泥。
- 用**细孔**擦泥器口感更细腻，注意别伤到手。
- 擦好的土豆接触空气会氧化变色，在意颜色的话动作要快。
- 晾凉后**尽早揪成小块**，放久会粘手。

**炸土豆团子**：把团子用保鲜膜搓成棒后切成 **15 等份**，**180℃ 炸 3～4 分钟**；趁热撒青椒粉和盐食用。

### 圣诞树土豆团子焗烤（3～4 人份）

| 材料 | 用量 |
| --- | --- |
| 擦土豆团子（用上一节的量，**不要用保鲜膜包**） | 1 根的分量 |
| 西兰花 | 1 棵 |
| 融化型芝士 | 100g |
| 胡萝卜（星形） | 少许 |
| 红、黄甜椒（花形） | 少许 |
| 橄榄油 | 适量 |
| 盐 | 少许 |
| 帕玛森芝士粉 | 适量 |

1. 西兰花掰成小朵，根部削薄当作树干；胡萝卜、甜椒用模具压出形状，胡萝卜快速焯一下。
2. 做好土豆团子，趁温热放入耐热盘，压成三角形圣诞树。
3. 西兰花插在土豆团子上摆成树形，根部安在树干位置。
   - **关键点：西兰花只焯水，不煮，烤的时候保持「生的」**。高温烤到出现焦斑会让花球的辛辣成分发生变化，产生类似烤肉的香气，和土豆团子的鲜味非常合。
4. 撒盐、淋橄榄油，芝士铺满盘子的缝隙，用烤面包机烤 **10～15 分钟**。
5. 摆上胡萝卜和甜椒，像撒雪一样撒上芝士粉。

### 土豆泥卡仕达酱（2 人份）

| 材料 | 用量 |
| --- | --- |
| 擦成泥的土豆 | 大勺 3 |
| 砂糖 | 大勺 3 |
| 牛奶 | 200mL |
| 黄油 | 10g |
| 蛋黄 | 2 个 |

1. 碗中放蛋黄打散，加入土豆泥、砂糖、牛奶，搅拌并过筛。
2. 倒入锅中加热，用刮刀边搅拌边煮出黏稠度。
3. 最后加入黄油煮匀收尾。

**变体：土豆泥芭菲**：高脚杯中依次叠放格兰诺拉、蓝莓酱、猕猴桃、土豆泥卡仕达酱、鲜奶油，顶上装饰草莓和薄荷叶即可。

### 焦糖红薯沙拉（2 人份）

| 材料 | 用量 |
| --- | --- |
| 热水 | 50mL |
| 蒜片 | 3～4 片 |
| 盐（做大蒜水用） | 1 撮 |
| 细砂糖 | 100g |
| 水 | 大勺 2 |
| 红薯 | 1 根 |
| 炸油 | 适量 |
| 沙拉叶 | 适量 |
| 盐 | 少许 |
| 橄榄油 | 少许 |

1. 沸腾的 **50mL** 热水加入蒜片和 **1 撮盐**，煮 **5 分钟**做成大蒜水。
2. 红薯切成较小的滚刀块，**170℃ 油温炸 4～5 分钟**。
3. 锅中放细砂糖 **100g** 和大勺 2 水，中火偏强并不时晃锅，加热 **3 分半**至焦糖状态，加入大蒜水轻轻拌匀，再加入红薯块充分拌匀。（也可以移到碗里拌。）
4. 沙拉叶与盐、橄榄油拌匀装盘，堆上红薯即可。

## 杏鲍菇：整根烤才有汁

杏鲍菇的隐藏功能是——**只要换一种做法，就能变得出奇多汁**。

它原产于地中海气候下的干燥地带，为了在干旱中活下来，体内蓄积了大量**海藻糖**这种保水力强的物质。正是它撑住了杏鲍菇的含水量，所以即使烤也不会失去多汁感。

问题出在切法上：一旦切成片，那层吸水的表皮就会从**断面**把水分蒸发掉。

所以结论很简单：想吃到惊人的多汁杏鲍菇，就**整根烤**。

→ 完整做法见[杏鲍菇怎么切？四种 5mm 刀法，黄油煎 4 分钟](./eringii.md)。

## 土豆：擦泥才能激活黏性

土豆淀粉的隐藏功能是**惊人的黏性**。对比实验中，土豆淀粉的黏度是玉米淀粉的 **8 倍以上**（实测读数：土豆 250、红薯 67、玉米 30，实验协力：日本农研机构）。

原理不复杂：淀粉加热时会吸水膨胀，与周围颗粒接触后就不易流动；而土豆淀粉的颗粒比别的淀粉**大**，因此吸水后膨胀得更厉害，这就是「惊人黏性」的真相。

但默认状态下，淀粉颗粒被坚固的细胞壁包裹着，普通做法根本调不出它的真正实力。诀窍是**擦泥**：一旦用擦泥器破坏细胞壁，淀粉颗粒就释放出来了。

擦泥还有一层额外好处——**提升鲜味**。土豆中的糖和氨基酸在加热时发生反应，会生成大量**甲硫醛**这种香气成分。说明书说，闻到这个气味会让人更容易感觉到鲜味。^[[「食材の隠し機能」のトリセツ](https://at.web.nhk/files/torisetsu-show/2025_syokusp_mkmw.pdf)]

→ 完整做法见[土豆：冷一晚出抗性淀粉，磨泥出黏性](./potato.md)。

## 大蒜：泡热水才出得来鲜味

大蒜的隐藏功能是**增强鲜味与醇厚感**。起作用的成分是大蒜含有的**醇厚味物质（コク味物質）alliin（蒜氨酸）**。只要在料理中放一点点，**几乎不会妨碍料理原有的味道和香气**，同时把鲜味和醇厚感拉起来。

问题出在处理方式：一旦**切碎或擦泥**，alliin 就会与酶发生反应，变成另一种香味物质 **allicin（大蒜素）**——蒜味就是这时候产生的。

让 alliin 存活的方法只有一个：**把切好的蒜片放进热水（汤）里**。热能让酶停止活动，alliin 便无法变成 alicin；同时易溶于水的 alliin 会从细胞内转移到水里。

说明书据此开发了一种万能调味料——**大蒜水**：

- **汤用（蒜香弱）**：沸水 **500mL** ＋ 蒜片 **3g（约 2～3 片）**，煮 **5 分钟以上**即成。可与食材一起煮。做汤用量足够 1～2 人份。
- **炒菜、蛋用（蒜香中）**：沸水 **100mL** ＋ 蒜片 **9g（1～2 瓣）** ＋ 盐 **2 撮**，煮 **5 分钟**。加盐能让醇厚味物质更好地析出。做炒菜用量足够 3～4 人份。
- **用法**：提前做好，炒菜时连同食材一起下锅，**炒到水分充分挥发**即可。

食用量的上限也要注意：过量食用大蒜会引起腹泻，参考量是**生蒜 1 瓣、加热过的蒜 2～3 瓣**。

→ 完整做法见[大蒜别磨蒜泥？切片泡 90℃ 热水 10 分钟](./garlic.md)。

牛油果买回来**硬邦邦的**，等不及它自然变软？

这篇给**煮牛奶催熟**这一招，外加它延伸出来的三道热菜、两道混进肉馅的主菜、「稍微加一点」的配角用法，和发褐后打成果昔的救场法。具体做法是：**牛油果果肉切块放入沸腾的牛奶中，中火煮 10 分钟**——此过程中**细胞间的果胶会被破坏**，使果实进入说明书所说的「反式消除」状态，**甚至坚硬的牛油果也会迅速变软，口感更加奶油滑腻**；**若仅需使用果肉，捞出后可放入冰箱冷藏 20 分钟再用**。

牛油果与其他水果不同，即使在刚收获时，其鲜味成分、营养成分和决定质地的脂肪含量几乎与完全成熟时相同。也就是说，**牛油果成熟后只会变得更软**。

要使牛油果变软，需破坏细胞间隙中的果胶，这种物质如同粘合剂，呈弱碱性且对热敏感。

牛油果广泛应用于泡面、鸡肉丸及日常蒸煮菜肴中，能增加风味和营养。

## 「稍微加一点」：牛油果是万能配角

说明书把牛油果称为**「什么都能派上用场的王者」**，理由很直接：它含有与橄榄油相同的**油酸**领衔的脂肪酸，脂肪含量在水果界名列前茅，同时又富含**谷氨酸**等鲜味成分。哪怕只加一点点，菜的醇厚感和鲜味都会明显上一个台阶。

已经验证过的「稍微加一点」去处：

- **汉堡饼、肉饼**：把牛油果混进肉馅，口感更润。
- **炸鸡柳**：黏稠的果肉能让容易发柴的炸物做出来更润。
- **味噌汤、关东煮、乌冬面、炒青菜**：做点睛式的一小块即可。^[[「アボカド」のトリセツ](https://at.web.nhk/files/torisetsu-show/2022_avocado.pdf)]

顺带一提，牛油果的历史可以追溯到大约 **1 万年前**——那时它凭丰富的脂肪，养活过身高超过 **5m** 的巨型生物。

## 牛奶煮的延伸：三道热菜

牛奶催熟不只是为了直接吃。说明书给出三道成谱，注意其中的共同铁律：**牛油果一煮过头就会发苦**，所以要么按分钟卡住，要么趁温热吃掉。

### 牛油果沙拉（2 人份）

| 材料 | 用量 |
| --- | --- |
| 牛油果 | 1 个（切 **7～8mm** 厚片） |
| 牛奶 | 500mL |
| 橄榄油 | 适量 |
| 盐 | 适量 |
| 柠檬汁 | 适量 |
| 柠檬皮屑 | 适量 |

1. 锅中倒牛奶加热，沸腾后放入牛油果，**中火煮约 10 分钟**，期间不时搅拌并注意别溢锅。
2. 捞出牛油果，沥掉牛奶，摆入餐盘。
3. 放入冰箱冷藏 **约 20 分钟**。
4. 淋橄榄油、撒盐和柠檬汁，最后刨上柠檬皮屑；喜欢的话加点香草。

### 牛油果浓汤（2 人份）

| 材料 | 用量 |
| --- | --- |
| 牛油果 | 1 个（切 **2cm** 方块） |
| 洋葱 | 1/2 个（切瓣） |
| 通心粉 | 50g |
| 牛奶 | 600mL |
| 低筋面粉 | 大勺 1 |
| 橄榄油 | 大勺 1 |
| 市售浓汤块 | 1 个（6g） |
| 盐、胡椒 | 少许 |

1. 平底锅中放橄榄油、洋葱和低筋面粉，**中火炒 2 分钟**。
2. 加牛奶，煮沸后放入牛油果和通心粉；重新沸腾后加入浓汤块转小火，不时搅拌煮 **约 15 分钟**。
3. 最后用盐和胡椒调味。

### 牛油果担担面（2 人份）

| 材料 | 用量 |
| --- | --- |
| 牛油果 | 2 个 |
| 牛奶 | 600mL |
| 水 | 200mL |
| 豆瓣酱（甜面酱） | 小勺 2 |
| 芝麻油 | 小勺 2 |
| 蒜末 | 小勺 2 |
| 姜末 | 小勺 2 |
| 鸡精 | 大勺 2 |
| 酱油 | 小勺 2 |
| 白芝麻 | 小勺 2 |
| 中華麺 | 2 袋 |

1. 牛油果去皮去核，切 **1cm** 厚片。
2. 锅中倒牛奶，沸腾后放入牛油果，**中火煮约 10 分钟**至变软。
3. 平底锅放芝麻油、蒜末、姜末，中火炒出香味后加豆瓣酱继续炒。
4. 把第 3 步倒入第 2 步，加鸡精、水和酱油；放入**煮得偏硬**的中華麺和白芝麻，中火轻煮入味。

## 混进肉馅的两道主菜

### 牛油果汉堡饼（2 人份）

| 材料 | 用量 |
| --- | --- |
| 熟牛油果 | 100g（约 1 个小果） |
| 猪牛混绞肉 | 200g |
| 洋葱末 | 30g |
| 盐 | 小勺 1/4（1.5g） |
| 葛粉 | 小勺 2 |
| 面包糠 | 大勺 3 |
| 油 | 大勺 1 |

1. 牛油果去皮去核，用叉子压碎，加入葛粉拌匀备用。
2. 碗中放绞肉和盐，**搅打至出黏性**。
3. 加入第 1 步的牛油果、洋葱末和面包糠，混合均匀，分成两份，排气后整形成小饼状。
4. 平底锅倒油，摆入肉饼，**中火煎约 3 分钟**。
5. 煎出焦色后翻面，盖盖**小火再煎 5～6 分钟**。肉饼很软，翻面时动作要轻。

### 牛油果肉饼卷（2～3 人份）

| 材料 | 用量 |
| --- | --- |
| 熟牛油果 | 1 个 |
| 猪牛混绞肉 | 200g |
| 水煮蛋 | 2 个 |
| 洋葱末 | 30g |
| 盐 | 小勺 1/4（1.5g） |
| 面包糠 | 大勺 3 |
| 胡椒 | 少许 |
| 低筋面粉 | 适量 |

1. 牛油果去皮去核压碎；绞肉加盐搅打至出黏性后，与牛油果、洋葱末、面包糠混合均匀。
2. 水煮蛋整体薄薄拍一层面粉。
3. 在烘焙纸上把肉馅摊成厚薄均匀的片，放上横放的水煮蛋包裹；整体整理成椭圆，**上下翻转一次让两端口合拢**，外面再裹一层铝箔，整形。
4. 放入**带余温的 180℃ 烤箱下层烤 30 分钟**。
5. 为上色，先打开铝箔和烘焙纸的上部，再在 **210℃ 烤 10 分钟**。
6. 取出后重新封上，晾到不烫手——成品很软，容易散，切的时候要等它彻底定形。

防破裂要点：包蛋时不要留空气；包好后把合口朝下压实，再用烘焙纸和铝箔包住，就不容易爆开。

## 已经变色的牛油果：打成果昔

**发褐**不等于坏。说明书给的处置办法是做成果昔，颜色问题就消失了：

| 材料 | 用量（2 人份） |
| --- | --- |
| 牛油果 | 1 个 |
| 牛奶 | 300mL |
| 酸奶 | 60g |
| 蜂蜜 | 50g |
| 柠檬汁 | 少许 |
| 冰块 | 2～3 颗 |
| 巧克力糖浆 | 适量 |

1. 除巧克力糖浆外的材料放进搅拌机，打到顺滑。
2. 杯壁上淋一层巧克力糖浆做装饰，再倒入第 1 步。

注意：有**霉斑或腐败气味**的牛油果不要吃。

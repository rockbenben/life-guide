打鼾常被当成睡得香的证据，而说明书把它放在完全不同的位置上：鼾声是气流穿过变窄气道时柔软组织振动的结果，而在鼾声的背后，可能是一种让人睡着后反复停止呼吸的病。日本估计约 2200 万人患闭塞性睡眠呼吸暂停症，900 万人需要治疗，实际接受治疗的只有约 80 万——9 成以上的人从未察觉。^[[「いびき」のトリセツ](https://at.web.nhk/files/torisetsu-show/2025_ibiki_tstm.pdf)]

这套做法不复杂：先用照镜子这一招把风险分到四档，再决定要不要去专科门诊。整套自查不需要任何设备。

## 鼾声背后，气道被什么堵住了

主要原因是舌和悬雍垂（小舌头）在重力或肌肉松弛时下落，气道因此变窄。气流通过狭窄处时，舌和悬雍垂这些柔软组织发生振动，声音在喉和口腔里被放大，成为鼾声。平时不打鼾的人，喝了酒或疲劳后开始打鼾，正是因为肌肉放松、舌和悬雍垂比平时垂得更低。

如果这些软组织继续下落，把气道完全或部分堵住，睡眠中就会出现呼吸停止。程度由专业机构做睡眠检查后得出的 AHI 衡量：一小时内无呼吸与低呼吸的总次数，其中低呼吸指浅呼吸持续 10 秒以上。有打鼾等症状、AHI 在 5 以上即判定为睡眠呼吸暂停症。

## 九成的人被漏掉了

日本国内的推算是：约 2200 万人患此病，900 万人需要治疗，实际治疗的只有约 80 万。漏掉的原因很直白——鼾声响，家人早已习惯，而呼吸暂停发生在睡着时，本人没有自觉。

放着不治的后果也有长期数据。说明书引用美国威斯康星州的一项追踪调查：30 到 60 岁的男女共 1522 人，随访 18 年，健康人的死亡率不到 1 成，而未治疗、放任不管的重症睡眠呼吸暂停症患者中，超过 4 成的人去世。

## AHI 分级：5、15、30 三个分界

AHI 不只是个判定门槛，它同时决定了**严重程度**和**要不要治**：

| AHI（每小时无呼吸+低呼吸总次数） | 严重程度 |
| --- | --- |
| **5 ～ 15 未满** | 轻度 |
| **15 ～ 30 未满** | 中度 |
| **30 以上** | 重度 |

有鼾声等症状、AHI 在 **5 以上**即判定为睡眠呼吸暂停症；而说明书明确写着**中度以上需要治疗**。所以「刚过 5」和「刚过 15」是两个完全不同的处境。^[[「いびき」のトリセツ](https://at.web.nhk/files/torisetsu-show/2025_ibiki_tstm.pdf)]

## 一夜之间血氧掉到 50%

正常呼吸时，血中血氧饱和度约 96% 到 99%。重症患者在夜里有时会降到 50% 上下——说明书指出，这个水平相当于身处珠穆朗玛峰顶上。

血氧饱和度低于 90% 时，脑内缺氧，为了把氧送进大脑，心跳加快、血压升高。一夜之间反复发生，就走向高血压；血管和心脏承受额外负担，与心肌梗死、脑卒中的风险连在一起。长期的慢性缺氧还会给胰腺和脑细胞增加负担，与糖尿病、认知功能下降相关。

## 5 秒自查：看悬雍垂和下颌

说明书给的办法是：不出声，把嘴张大，伸出舌头到底，看悬雍垂。按能看到的部分分成四档：

1. Class I：全部看得见
2. Class II：除了尖端以外看得见
3. Class III：只有根部勉强看得见
4. Class IV：完全看不见

日常就打鼾、且属于 Class III 或 Class IV 的人，睡眠呼吸暂停症的风险较高。

说明书把成因归到两条：一是肥胖，舌根比舌尖更不容易活动，也更容易堆积脂肪，睡着时尤其容易靠舌头把气道压窄；二是下颌偏小，口腔内部变窄，舌放不进去，睡着后容易大幅后坠。**下颌偏小这条常被漏掉**——说明书写明，日本人的睡眠呼吸暂停症中 4 成以上并非肥胖造成。

下颌大小也能自己看：用尺子、食指等笔直的东西连接鼻尖与上唇，看下颌是否落在这条直线上。像图中左侧女性那样稳稳落在直线上的，说明下颌不算小；如果像右侧那样离开了直线，下颌偏小的可能性就存在。

## 说明书给的睡姿调整

针对鼾声本身，说明书列了两条方向。

一是**侧卧**。换方向睡能防止舌后坠、确保气道通畅，有改善鼾声的效果。筑波大学名誉教授佐藤诚提到，要长时间保持侧卧，需要用与躯干同样粗细的抱枕来分散体压。

二是**嗅探姿势**。像"闻气味"那样在颈下垫一条毛巾，把鼻子稍微抬起，把头部调到更容易呼吸的位置。说明书同时提醒：枕头垫得过高会压迫神经，可能引起颈部疼痛和肩周炎，出现不适就停止。

## 什么时候该去医院

- **悬雍垂属于 Class III 或 Class IV**：说明书把这类人直接指向专科门诊。
- **悬雍垂属于 Class I 或 Class II，但同时有肥胖或下颌偏小**：同样建议咨询专科医生。
- **两项都不符合，但日常打鼾、自己也担心**：说明书写明，这类人也可以去咨询。
- **起床时口很渴、早上总是觉得没睡够**：这两条被说明书列在检查表的另一侧，是值得留意的信号。

真正判断呼吸暂停的程度，需要专业机构做睡眠检查得出 AHI，中等症以上才需要治疗。专科医生可以从日本睡眠学会或日本睡眠牙科学会的网站查找，两处都列有睡眠医疗认定的专科名单。

至于医疗处置本身，口腔矫治器主要面向轻症到中等症，CPAP 主要面向中等症到重症；后者需在专科门诊确诊、睡眠检查结果 AHI 达到 20 以上，才符合保险适用条件。是否适合自己、如何使用，请由专科医生判断。

> [!IMPORTANT]
> 鼾声突然停下的那几秒，可能不是睡得沉，而是呼吸停了。按说明书给的规则自查属于 Class III 或 Class IV、日常就打鼾又在意这件事的人，应当去睡眠专科门诊看看。

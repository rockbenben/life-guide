「钾活卡片」的用法只有两条，两句话就印在每张卡的表头：**每张卡片 = 300mg 钾**、**每天在正餐里加入 4 张以上**——4 张 × 300mg = **1200mg**，这就是整套卡片每天要额外补上的目标线。整套共 **36 张**卡片，下面按颜色列出每张对应的食材和分量（绿色 11 张、粉色 9 张、红黄 7 张、蓝橙 9 张），照着分量取量即可。前提只有一句：摄取钾是"减盐"的辅助手段，**不能代替减盐**。^[[「カリ活カード」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_kalikatsucard_kaea083.pdf)]

## 目标：每天额外 1200mg

整套卡片的规则只有两条，而且两句话就写在每张卡的表头：

- **每张卡片 = 300mg 钾**
- **每天在正餐里加入 4 张以上卡片**

4 张 × 300mg = **1200mg**，这就是整套卡片的目标线。整套共 **36 张**卡片，全部算齐可提供 **10800mg** 钾（36 × 300mg）。

需要先说清楚的一点：每张卡片边缘都印着同一句注记——**摄取钾是"减盐"的辅助手段**。它不能代替减盐，而是在减少钠的基础上补一份钾。

> **注意**：说明书没有写这一条，但**慢性肾病、或正在服用降压药（尤其 ACEI／ARB）与保钾利尿剂的人不要自己加钾**——高钾血症会危及心脏，这类人先问医生。

## 绿色卡：蔬菜、水果与豆荚（11 张）

这一组是卡片数量最多的一类，从绿叶菜一直到热带水果。

| 食材（生） | 一张卡的分量 |
| --- | --- |
| 芹菜 | 1 根 **70g** |
| 卷心菜 | **160g** |
| 生菜 | **150g** |
| 茄子 | 中等 1.5 根 **140g** |
| 毛豆 | **50g** |
| 玉米罐头 | 1 罐 **230g** |
| 橙子（去皮） | 2 个 **200g** |
| 橘子 | 2 个 **200g** |
| 香蕉 | 2/3 根 **80g** |
| 牛油果 | 1/2 个 **50g** |
| 猕猴桃 | 1 个 **100g** |

值得注意的是，香蕉的分量偏小（**2/3 根 80g**），香蕉这类密度高的食物，一张卡对应的量就少。^[[「カリ活カード」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_kalikatsucard_kaea083.pdf)]

## 粉色卡：薯类、根菜与菌菇（9 张）

根茎与菌菇各自都能贡献一张 300mg。

| 食材 | 一张卡的分量 |
| --- | --- |
| 芋头（生） | 1 个 **50g** |
| 烤红薯（去皮） | 1/3 根 **60g** |
| 带皮土豆（生） | 1/2 个 **70g** |
| 白萝卜（生） | 切成 3cm 圆片 **130g** |
| 干し芋（干红薯） | 2 张 **30g** |

| 金针菇 | 约 1 盒 **90g** |
| 杏鲍菇 | 2～2.5 根 **90g** |

## 红黄卡：豆制品与奶类（7 张）

豆腐的用量按整块计——绢豆腐和北豆腐的分量差异不小。

| 食材 | 一张卡的分量 |
| --- | --- |
| 绢豆腐 | 2/3 块 **200g** |
| 北豆腐 | 1 块 **270g** |
| 纳豆 | 1 盒 **50g** |
| 黄豆粉 | 2 大勺 **15g** |
| 牛奶 | 1 杯 **200mL** |
| 酸奶 | **180g** |
| 豆浆 | 1 杯（**略浅**） **160mL** |

黄豆粉一张卡只要 **15g**，已经算小的了（比它更小的是滑海带，一张卡只要 **6g**）；牛奶、酸奶、豆浆则按杯或克数计，不按固体重量。

## 蓝橙卡：海产与肉类替换（9 张）

海产类有 6 张，全部按"刺身几片"这种**可数单位**来标。

| 食材 | 一张卡的分量 |
| --- | --- |
| 真鲷 | 刺身 4 片 **60g** |
| 金枪鱼 | 刺身 5 片 **70g** |
| 扇贝（贝柱） | 3 个 **80g** |
| 鰤鱼 | 2/3 片 **80g** |
| 三文鱼 | 刺身 5 片 **80g** |
| 滑海带 | **6g** |

最后 3 张是肉类替换卡，画法是"用箭头从肥的换到瘦的"，让你在不改变卡片数量的前提下降低脂肪：

| 替换前 → 替换后 | 一张卡的分量 |
| --- | --- |
| 五花肉 → 猪里脊 | **160g** |
| 西冷牛排 → 牛里脊 | **160g** |
| 鸡腿肉 → 鸡胸肉 | **250g** |

替换后三者的分量都比替换前大，说明同样一份卡，换成瘦肉后可以吃到更多。^[[「カリ活カード」のトリセツ](https://at.web.nhk/files/torisetsu-show/2024_kalikatsucard_kaea083.pdf)]

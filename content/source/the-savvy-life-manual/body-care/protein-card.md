这套卡片的用法只有一条：**一餐用 3 种颜色的卡片搭配**，让菜单更完整，**合计蛋白质 20g 以上**。每张卡左上角星形里的数字就是那一份的**蛋白质克数**，卡片下方标注对应分量——比如白米饭一张卡是 **3g** 蛋白质、**150g** 分量（一碗）。下面按黄（主食 12 张）、绿（植物 12 张）、红（动物 16 张）三色列出全部 **40 张**卡，照着数字搭配就行，**用数字代替感觉**。^[[「かん・たんカード」のトリセツ](https://at.web.nhk/files/torisetsu-show/2025_kantancard.pdf)]

## 一张卡只回答一件事

每张卡的左上角有一个星形数字，那是**该份食物的蛋白质克数**；卡片下方标注的是**对应的分量**。比如白米饭一张卡是 **3g** 蛋白质，**150g** 分量（一碗）。

整套卡片由**神奈川县立保健福祉大学铃木志保子教授**监修。

## 三色搭配：每餐 3 色、合计 20g 以上

卡片按**食材系**分成三种颜色：

| 颜色 | 分组 | 张数 |
| --- | --- | --- |
| 黄色 | 主食系 | **12** 张 |
| 绿色 | 植物系 | **12** 张 |
| 红色 | 动物系 | **16** 张 |

说明书给出的用法是：**一餐用 3 种颜色的卡片来搭配**，让菜单更完整，**合计蛋白质 20g 以上**。全部 **40** 张卡里，单张最高的是荞麦面和中华面（各 **10g**）；最低的一档是 **1g**，带皮马铃薯、带皮红薯、山药和炒核桃都落在这一档。

## 黄色卡（主食系）：12 张

| 食材 | 蛋白质 | 分量 |
| --- | --- | --- |
| 可颂 | **3g** | 1 个 **45g** |
| 无糖玉米片 | **3g** | 1 份 **50g** |
| 白米饭 | **3g** | 1 碗 **150g** |
| 糙米饭 | **4g** | 1 碗 **150g** |
| 燕麦片 | **4g** | 干重 **30g**（1 餐） |
| 吐司 | **4g** | 1 片（6 片切）**60g** |
| 葡萄干面包 | **5g** | 1 片（6 片切）**75g** |
| 乌冬面 | **5g** | 1 团 **200g** |
| 菠萝包 | **6g** | 1 个 **90g** |
| 豆沙包 | **7g** | 1 个 **120g** |
| 荞麦面 | **10g** | 生重 **120g**（1 团） |
| 中华面 | **10g** | 生重 **120g**（1 团） |

同一组里差别很大：荞麦面和中华面各 **10g**，是可颂与白米饭（各 **3g**）的三倍多。同样写着"一张卡"，主食之间的差距就是这么直接。

| 食材 | 蛋白质 | 分量 |
| --- | --- | --- |
| 带皮马铃薯 | **1g** | 生重 **100g**（1 个） |
| 带皮红薯 | **1g** | 生重 **100g** |
| 山药 | **1g** | 生重 **50g** |
| 炒核桃 | **1g** | 5 小把 **10g** |
| 厚油豆腐皮 | **2g** | **20g**（1/9 块） |
| 花生 | **2g** | **10 粒**（**10g**） |
| 豆腐 | **3g** | **50g**（1/6 块） |
| 煮黄豆 | **3g** | **1 大勺（山盛）20g** |
| 纳豆 | **4g** | 迷你杯 1 盒 **30g** |
| 煮毛豆 | **5g** | **100g**（可食部 **50g**） |
| 豆浆 | **5g** | 浅装 1 杯 **150g** |
| 干高野豆腐 | **8g** | 1 块 **17g** |

这一组的跨度从 **1g** 到 **8g**：一份只有 **1g** 的带皮马铃薯，要凑到 **8g** 得靠一小块干高野豆腐——植物系同样存在高密度选项（但全卡的顶点仍是荞麦面、中华面那两张 10g）。

> **注意**：**肾脏有疾病的人如果摄入过多蛋白质，可能会导致病情进展**，请务必**咨询主治医生**。
